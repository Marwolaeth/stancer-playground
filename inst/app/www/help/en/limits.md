### Analysis Limits

This parameter allows you to control the scope of your batch processing.

#### Number of rows to analyse:
*   **Definition**: Specifies how many rows from the uploaded dataset will be processed in the current run.
*   **Purpose**: Since LLM analysis can be time-consuming and involves API costs, this limit helps you run tests on small samples (e.g. the first 5–10 rows) before committing to a full-scale analysis of the entire corpus.
*   **Range**: You can select between 1 and 20 rows for a single playground session.
