### Model Name

Enter the specific model identifier.

*   **For OpenRouter**: Use the format `author/model-name` (e.g., `google/gemini-2.0-flash-001`).
*   **For Direct Providers**: Use the standard ID (e.g., `gpt-4o` or `claude-3-5-sonnet-latest`).

Ensure your API key has access to the chosen model.
