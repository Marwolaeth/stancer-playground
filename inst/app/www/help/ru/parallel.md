#### Параллельная обработка

*   **Как это работает**: При включении этой опции приложение отправляет несколько запросов к провайдеру LLM одновременно, используя механизмы параллелизации библиотеки `ellmer`.
*   **Преимущество**: Значительно сокращает общее время, необходимое для анализа больших наборов данных.
*   **Важно**: Параллельные запросы быстрее расходуют лимиты вашего API (RPM/TPM). Если вы сталкиваетесь с ошибками "Rate Limit", попробуйте отключить эту опцию для последовательной обработки строк.
