### Импорт данных и анализ корпуса

Этот раздел позволяет загрузить ваш собственный набор данных (корпус) для массового анализа. Система предназначена для работы с табличными данными, где каждая строка представляет собой отдельный документ.

#### Основные возможности:

*   **Загрузка файла**: Загрузите собственный файл CSV или Excel, содержащий тексты.
*   **Использование примера**: Если у вас нет готового набора данных, нажмите кнопку **«Использовать пример»**. Будет загружен датасет `programming_tweets` из библиотеки `stancer` — коллекция из 35 вымышленных твитов о языках программирования Julia, Python и R.

#### Настройка колонок (Column Mapping):
После загрузки данных необходимо назначить роли вашим переменным:
*   **Текст документа**: Колонка, содержащая основной текст для анализа.
*   **Объект тональности**: (Необязательно) Колонка, указывающая объект отношения. Если выбрана, объект будет динамически обновляться для каждой строки.
*   **Тип анализа**: (Необязательно) Колонка, определяющая тип объекта. Должна содержать значения `Object` (для отношения к сущности) или `Claim` (для оценки степени согласия с утверждением/тезисом). Если выбрана, тип анализа будет динамически меняться для каждой строки.
*   **Истинные метки**: (Необязательно) Колонка, содержащая ваши «эталонные» значения. Она необходима, если вы планируете использовать функцию **Scoring** для оценки качества работы модели.
