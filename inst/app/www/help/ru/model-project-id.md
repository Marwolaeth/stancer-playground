### ID проекта Yandex Cloud

Укажите идентификатор каталога (папки) в Yandex Cloud, в котором создан сервисный аккаунт для доступа к YandexGPT API. Этот идентификатор используется при формировании `modelUri` в запросах к моделям Yandex Foundation Models.

**Где взять идентификатор:**

1. Откройте [консоль управления Yandex Cloud](https://console.cloud.yandex.ru).
2. На панели сверху выберите нужный каталог (папку).
3. Идентификатор отображается:
   - **Сверху**, под именем каталога, либо
   - Справа от названия каталога нажмите «⋮» → **Информация о каталоге** → поле **Идентификатор**.

**Пример:** `b1gsm26ta12sfo8jpbgr`

**Как используется:**

Идентификатор подставляется в `modelUri` при обращении к API, например:

```
gpt://b1gsm26ta12sfo8jpbgr/yandexgpt-lite
```

**Важно:** У сервисного аккаунта, чей API-ключ вы используете, должны быть назначены роли `ai.languageModels.user` и/или `ai.foundationModels.user` на этот каталог. Без них запросы будут отклоняться с ошибкой доступа.
